# Estado y hoja de ruta

ReboNotes está en la versión 0.1: cada paquete escrito y probado, nada en npm todavía.

## Hecho

- El motor: páginas, bloques, el árbol, enlaces y retroenlaces, búsqueda sin importar mayúsculas ni acentos, Markdown de ida y vuelta, carpetas y .zip.
- El editor: todos los bloques, Markdown al escribir, el menú `/`, `[[`, la barra sobre una selección, arrastrar bloques, seleccionar bloques enteros, pegar Markdown, imágenes y archivos, búsqueda rápida, un historial entre páginas, claro y oscuro, inglés y español.
- Bases de datos: columnas de un tipo, tablas y tableros, ordenar, fórmulas con el motor de Rebosheets.
- Archivos en una página: los visores de Rebosheets, ReboSlides y Rebodocs; PDFs, videos y audio; con tamaño a mano.
- Colaboración bloque por bloque, con presencia; deshacer solo lo propio.
- Un servidor MCP con 20 herramientas; un componente de React y hooks headless.
- Una app de escritorio: una carpeta de archivos Markdown como espacio de trabajo.

## Todavía no

- Texto fusionado letra por letra cuando dos personas escriben en el mismo bloque: ahí gana el último.
- Filtros y más vistas de una base de datos (calendario, galería), y abrir una fila como página.
- Comentarios, y un historial de versiones de una página.
- Los paquetes en npm.

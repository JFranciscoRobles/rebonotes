# Escribir en el editor

## Bloques

Escribe `/` en una línea para el menú de bloques, y sigue escribiendo para filtrarlo: texto, tres títulos, listas con viñetas, numeradas y de tareas, desplegables, citas, destacados, código, separadores, imágenes, una página dentro de esta, un enlace a una página, una base de datos, un tablero, un archivo, un enlace para insertar.

Markdown al principio de una línea hace el bloque que escribe:

| Escribe | Para |
| --- | --- |
| `#` `##` `###` y un espacio | Un título |
| `-` o `*` y un espacio | Una lista con viñetas |
| `1.` y un espacio | Una lista numerada |
| `[]` y un espacio | Una tarea |
| `>` y un espacio | Una cita |
| ```` ``` ```` | Código |
| `---` | Un separador |

Y en el texto: `**negrita**`, `*cursiva*`, `` `código` ``, `~~tachado~~`. Selecciona texto para la barra sobre él: el tipo de bloque, negrita, cursiva, subrayado, tachado, código, un enlace.

## Páginas y enlaces

`[[` abre una búsqueda de páginas: la elegida se enlaza en el texto, o se crea una nueva con lo que escribiste. Los enlaces a una página muestran su título, y cada página lista al pie las que enlazan a ella. ⌘K busca en todos los títulos y líneas.

## Mover bloques

Pasa el ratón sobre un bloque para ver sus asas: **+** añade un bloque debajo, el asa lo arrastra (con lo que tiene dentro) o, con un clic, abre su menú: eliminar, duplicar, mover, convertir en. Tab y Shift+Tab meten y sacan un bloque. Escape selecciona el bloque; luego ↑ ↓ mueven la selección, Shift la amplía, Suprimir la quita, ⌘C la copia como Markdown, ⌘D la duplica.

## Imágenes y archivos

Pega una imagen, o suelta archivos en la página. Las imágenes y archivos tienen asas a los lados para hacerlos más angostos o anchos, y los archivos que se muestran, una abajo para su altura.

## Atajos

| | |
| --- | --- |
| ⌘K · ⌘P | Buscar páginas (⌘K con texto seleccionado: un enlace) |
| ⌘B · ⌘I · ⌘U · ⌘⇧S · ⌘E | Negrita, cursiva, subrayado, tachado, código |
| Enter · ⇧Enter | Un bloque nuevo · un salto de línea |
| ⌘Enter | Marcar una tarea · abrir o cerrar un desplegable |
| ⌘D | Duplicar el bloque |
| ⌘⇧↑ · ⌘⇧↓ | Mover el bloque |
| ⌘Z · ⇧⌘Z | Deshacer · rehacer, entre páginas |
| ⌘\ | Ocultar o mostrar la barra lateral |

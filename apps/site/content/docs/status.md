# Status and roadmap

ReboNotes is at version 0.1: every package written and tested, nothing on npm yet.

## Done

- The engine: pages, blocks, the tree, links and backlinks, search without minding case or accents, Markdown both ways, folders and .zip.
- The editor: every block, Markdown as you type, the `/` menu, `[[`, the bar over a selection, dragging blocks, whole blocks selected, pasting Markdown, images and files, quick search, one history across pages, light and dark, English and Spanish.
- Databases: columns of a kind, tables and boards, sorting, formulas by Rebosheets' engine.
- Files in a page: the viewers of Rebosheets, ReboSlides and Rebodocs; PDFs, videos and sounds; resized by hand.
- Collaboration block by block, with presence; undo of one's own changes.
- An MCP server with 20 tools; a React component and headless hooks.
- A desktop app: a folder of Markdown files as a workspace.

## Not yet

- Text merged letter by letter when two people write in the same block: the last one wins there.
- Filters and more views of a database (calendar, gallery), and a row opened as a page.
- Comments, and a history of versions of a page.
- The packages on npm.

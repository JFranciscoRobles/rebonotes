# Writing in the editor

## Blocks

Type `/` on a line for the menu of blocks, and keep typing to narrow it: text, three headings, bulleted, numbered and to-do lists, toggles, quotes, callouts, code, dividers, images, a page inside this one, a link to a page, a database, a board, a file, a link to embed.

Markdown at the start of a line makes the block it writes:

| Type | For |
| --- | --- |
| `#` `##` `###` and a space | A heading |
| `-` or `*` and a space | A bulleted list |
| `1.` and a space | A numbered list |
| `[]` and a space | A to-do |
| `>` and a space | A quote |
| ```` ``` ```` | Code |
| `---` | A divider |

And in the text: `**bold**`, `*italic*`, `` `code` ``, `~~struck~~`. Select text for the bar over it: the kind of block, bold, italic, underline, strikethrough, code, a link.

## Pages and links

`[[` opens a search of the pages: the one chosen is linked in the text, or a new one made of what you typed. Links to a page show the page's title, and each page lists at its foot the pages that link to it. ⌘K searches every title and line.

## Moving blocks

Hover a block for its handles: **+** adds a block under it, the grip drags it (with what is inside it) or, clicked, opens its menu: delete, duplicate, move, turn into. Tab and Shift+Tab set a block in and out. Escape selects the block; then ↑ ↓ move the selection, Shift extends it, Delete takes it away, ⌘C copies it as Markdown, ⌘D duplicates it.

## Images and files

Paste an image, or drop files on the page. Images and files have handles on their sides to make them narrower or wider, and files shown, one under them for their height.

## Shortcuts

| | |
| --- | --- |
| ⌘K · ⌘P | Search the pages (⌘K on selected text: a link) |
| ⌘B · ⌘I · ⌘U · ⌘⇧S · ⌘E | Bold, italic, underline, strikethrough, code |
| Enter · ⇧Enter | A new block · a line break |
| ⌘Enter | Tick a task · open or close a toggle |
| ⌘D | Duplicate the block |
| ⌘⇧↑ · ⌘⇧↓ | Move the block |
| ⌘Z · ⇧⌘Z | Undo · redo, across pages |
| ⌘\ | Hide or show the side |
